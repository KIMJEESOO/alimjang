한 줄 알림장 - 오프라인 설치판 배포 안내

이 폴더(index.html, manifest.webmanifest, sw.js, icons)를 통째로 인터넷 주소(https)에 한 번 올리면,
누구나 그 주소에 접속해 홈 화면에 설치할 수 있고, 설치한 뒤에는 인터넷 없이도 작동합니다.
(아이폰은 HTML 파일을 직접 열면 작동하지 않으므로 반드시 주소로 접속해야 합니다.)

[올리는 방법 1] Netlify Drop - 가장 쉬움, 무료
 1. 컴퓨터에서 https://app.netlify.com/drop 접속 (무료 회원가입 필요)
 2. 압축을 푼 '한줄알림장_설치판' 폴더를 화면에 끌어다 놓기
 3. 생성된 https://○○○.netlify.app 주소를 선생님들께 공유

[올리는 방법 2] GitHub Pages - 무료
 1. github.com 에서 새 저장소(Public) 만들기
 2. 'Add file → Upload files'로 폴더 안의 파일을 모두 올리기 (icons 폴더 포함)
 3. Settings → Pages → Branch를 main 으로 저장
 4. 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소를 공유

[선생님들이 설치하는 방법]
 - 아이폰: 사파리로 주소 열기 → 아래 공유 버튼 → '홈 화면에 추가'
 - 안드로이드: 크롬으로 주소 열기 → 화면의 '앱 설치' 버튼 (또는 메뉴 → 홈 화면에 추가)
 - PC: 크롬·엣지 주소창 오른쪽의 설치 아이콘
 설치 후 처음 한 번만 인터넷이 필요하고, 그다음부터는 비행기 모드에서도 열립니다.

[알아 둘 점]
 - 기록과 명단은 각 기기 안에만 저장됩니다. 다른 기기로 옮겨지지 않습니다.
 - 앱 데이터를 지우거나 앱을 삭제하면 기록도 사라집니다.
 - 오프라인에서는 칩과 '사진 속 모습' 고르기로 기본 양식 알림장을 만듭니다.
 - 사진 자동 분석과 AI 문장 다듬기는 인터넷이 연결된 상태에서, 설정의 'AI 연결'에
   Anthropic API 키를 넣은 경우에만 작동합니다(사용량만큼 키 주인에게 요금 부과).
 - 파일을 고쳐 다시 올리면, 선생님들이 앱을 인터넷 연결 상태로 한 번 열 때 새 버전으로 바뀝니다.
